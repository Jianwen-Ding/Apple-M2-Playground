# IEEE fp32 fma evidence (2026-10-20)

`exact.json.gz`: hardware (`hw`) and simulator (`sim`) outputs of `run_drm_softfp32.py` for soft-{rn,rz,rm,rp}, the hybrid,
and the native fmadd32 over the 21,024-lane edge/random dataset (regenerated by `dataset(12000)`). `cost.json.gz`: the
cost runs (`<op>-<data>-k<K>`, firmware ns per run; output arrays dropped). Check: `make verify-fp32-ieee`.
Limits: one device, AC power. The native K=1024 runs vary 2x with clock state, so the K=2048 point is used.
