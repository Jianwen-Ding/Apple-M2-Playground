# Driver time evidence — 2026-10-04

[Experiment report](../../experiments/timing/driver-time.md) explains scope,
source limitations, measurement method, failures, and next shader counter work.
Reproduce with `python3 -B scripts/run_time.py` from the canonical repository.

- `success/`: environment, build and four phase command logs, all 264 raw
  timestamp samples, source hashes, and calculated rate/bracket summary.
- `missing-device/`: retained failed open with errno 2 and status 1.
- `source-evidence.json`: immutable Asahi source URLs, hashes, selected excerpts,
  and the explicit unverified match to the running kernel build.
- `integration-review/`: corrected-runner hardware rerun (264 validated samples),
  non-DRM failure, and a reproducible synthetic runner regression check with JSON results.
- `verification.json`: compiler syntax check, invalid bound/nonnumeric failures,
  synthetic analysis checks, and timestamp lattice compatibility check.

Binaries remain in scratch and are regenerated by the runner. Historical scratch
paths in logs identify the original runs. Results demonstrate working, advancing
GET_TIME timestamps; no shader executed and no ISA latency was measured.
